  applyTheme() (line 23–26) ✅
  function applyTheme(theme) {
    document.documentElement.dataset.theme = theme;
    try { localStorage.setItem('theme', theme); } catch {}
  }
  - <html data-theme> 속성 변경 → CSS 변수 재정의 방식으로 테마 적용

  UI는 정상 동작

  }
  - 저장값이 없거나 이상한 값이면 자동으로 'light' 처리 — 방어적이고 안전

  }
